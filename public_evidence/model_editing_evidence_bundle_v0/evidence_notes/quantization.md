# Quantization Lane

This lane uses the existing tiny GPT-2 `quant_rtn` public run as a quantization
evidence example.

Evidence takeaways:

- Artifact mode: real tiny-model run.
- Verification surface: release/strict report verification and runtime
  provenance for one baseline-vs-subject comparison.
- Companion benchmark evidence: quantization quality, deployment performance,
  edit-quality, and safety evaluations when those questions are in scope.
