# LoRA-Merge Lane

This lane uses the public LoRA-merge BYOE fixture as an adapter-merge evidence
example.

Evidence takeaways:

- Artifact mode: public BYOE subject fixture.
- Verification surface: release/strict report verification plus optional edit
  provenance and edit-impact metadata for an external subject reference.
- Companion benchmark evidence: real PEFT training, adapter merge quality,
  edit-quality, locality, robustness, and safety evaluations when those
  questions are in scope.
