# Magnitude-Prune Lane

This lane uses the existing tiny GPT-2 external magnitude-prune public run as a
pruning evidence example.

Evidence takeaways:

- Artifact mode: real tiny-model external edit run.
- Verification surface: release/strict report verification, runtime provenance,
  and signed evidence-pack packaging for an externally produced subject.
- Companion benchmark evidence: pruning quality, sparse-runtime acceleration,
  edit-quality, and safety evaluations when those questions are in scope.
