# v0.9.0 Release Checklist

## Overview

| Aspect | Details |
| --- | --- |
| **Purpose** | Maintainer release-readiness gate for v0.9.0 strict assurance hardening. |
| **Audience** | Release managers and maintainers preparing v0.9.0 artifacts. |
| **Version scope** | v0.9.0 only; later releases should copy and update this checklist. |
| **Source of truth** | `docs/release/v0.9.0-assurance-hardening-plan.md`, `docs/assurance/trust-model.md`, `scripts/coverage_policy.py`, CI workflow configuration. |

This checklist is the maintainer-facing release-readiness gate for the strict
assurance hardening release.

## Artifacts

- [ ] Wheel and sdist built from the release branch.
- [ ] Wheel and sdist hashes recorded.
- [ ] SBOM generated.
- [ ] Runtime image digest recorded.
- [ ] Strict example report and verifier output recorded.
- [ ] Documentation build artifact produced.

## Gates

- [ ] `make lock-sync`
- [ ] `make security`
- [ ] `make cve-audit`
- [ ] `make contracts-check`
- [ ] `make docs-check`
- [ ] `make workflow-lint`
- [ ] `make dist-check`
- [ ] `make test-assurance`
- [ ] `make verify`
- [ ] `make coverage-enforce`

## Strict Assurance Acceptance

- [ ] `evaluate --assurance strict` defaults to fail-closed policy.
- [ ] `verify --assurance strict` rejects non-strict reports.
- [ ] Wrong or missing canonical guard chain is rejected.
- [ ] Repaired/synthesized metric evidence is rejected.
- [ ] Runtime provenance is verified.
- [ ] Unsupported guard/model cases block assurance.

## Security And PR Consolidation

- [ ] Dependabot alerts for `idna`, `pymdown-extensions`, `urllib3`, and `pip`
  are represented in this branch or already resolved.
- [ ] PR #19 CodeQL action SHA update is represented.
- [ ] PR #22 Ruff update is represented.
- [ ] PR #24/#25 dependency refresh content is represented where relevant.
- [ ] Code scanning has zero open alerts.
- [ ] Repository advisories have zero open alerts.
